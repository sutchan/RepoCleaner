# prototype/ 原型目录说明 v2.3.2

本目录是 Repo Manager 的**原型资料目录**，仅保留本说明文件，不含可运行代码，也不存放规范正文。

- **原型现状**：原先的 Next.js 参考界面已迁至仓库根 `src/`，作为参考界面应用保留（纯展示，v2.0.0 起已弃用，可 `npm run dev` 预览）。
- **规范位置**：全部规格与规范文档已归档到 [`docs/`](../docs/README.md)：
  - 产品功能规格 → [`docs/OPENSPEC.md`](../docs/OPENSPEC.md)
  - 开发规范 → [`docs/CONTRIBUTING.md`](../docs/CONTRIBUTING.md)
  - UI 设计规范 → [`docs/DESIGN-SYSTEM.md`](../docs/DESIGN-SYSTEM.md)
  - 设计令牌 → [`docs/tokens.json`](../docs/tokens.json)

- **落地页位置**：Web 展示项目的落地页面放 [`landing/`](../landing/README.md)，本目录不存放可运行页面代码，也不复述规范正文。

后续新增原型稿、设计截图或交互草图可放本目录；**规范文本一律写进 `docs/`，禁止在此重复维护**。
