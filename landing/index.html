七项功能

功能编号与命令行参数一致，可直接调用。

01

03

05

三步开始

1

取得程序

从 Release 下载对应平台归档，或用 Go 构建 repo-manager。

2

选择目录

GUI 选择目录或 CLI 传入路径，config.ini 可保存默认目录。

3

执行功能

点击功能按钮 1–7，或用 repo-manager <1-7> [路径]。

安全设计

  • 危险功能（1 / 6 / 7）执行前二次确认。
  • 预演模式只显示将执行的操作，不修改文件。
  • 递归扫描限制为 3 层，自定义清理目录名经安全校验。
  • 执行日志同步写入可执行文件同目录的日志文件。

常见问题

是否需要联网或上传项目数据？

不需要。工具在本地运行，不上传仓库内容；联网仅发生在功能 5 安装全局依赖时。

支持哪些操作系统？

Go 版支持 Windows、macOS 与 Linux 单二进制；GUI 运行需要系统 OpenGL，纯命令行可用 nogui 构建。

界面语言可以切换吗？

支持简体中文、繁体中文与英文；CLI 帮助固定为英文，不随语言切换。
